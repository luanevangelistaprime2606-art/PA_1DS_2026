# 📚 PA_1DS_2026 — Repositório de Algoritmos

## 📌 Sobre o Projeto

Este repositório reúne atividades e exercícios de **Programação e Algoritmos**, desenvolvidos durante o curso de Desenvolvimento de Sistemas — 1º ano (1DS), em 2026.

O projeto tem como finalidade armazenar e organizar os códigos desenvolvidos ao longo das aulas, permitindo acompanhar a aprendizagem e praticar os conceitos fundamentais da programação.

## 🎯 Objetivos do Sistema

- Desenvolver o raciocínio lógico e computacional.
- Praticar a construção de algoritmos.
- Compreender estruturas de repetição e decisão.
- Trabalhar com listas e estruturas de controle.
- Organizar e documentar os exercícios desenvolvidos durante as aulas.

## ⚙️ Principais Funcionalidades e Conteúdos

O repositório está organizado em pastas que representam diferentes exercícios e conteúdos de programação:

- **Laco3:** exercícios envolvendo estruturas de repetição.
- **LacoDoWhile:** prática com a estrutura de repetição `do-while`.
- **LacoFor:** exercícios utilizando a estrutura `for`.
- **LacoEnquanto:** exercícios com estruturas de repetição `while`.
- **LacoEnquanto2:** continuação das atividades envolvendo a estrutura `while`.
- **Lista02:** conjunto de exercícios de programação.
- **SwitchCase:** exercícios utilizando a estrutura de seleção `switch-case`.
- **SwitchCase2:** continuação das atividades com `switch-case`.
- **TomadaDecisão:** exercícios relacionados às estruturas condicionais e à tomada de decisões.

## 👥 Utilizadores

Este repositório é destinado principalmente a estudantes e professores da área de programação, servindo como material de estudo, prática e consulta dos algoritmos desenvolvidos.

## 🔄 Fluxo Operacional

1. Acessar o repositório no GitHub.
2. Escolher a pasta correspondente ao exercício desejado.
3. Abrir ou baixar os arquivos do código-fonte.
4. Executar os algoritmos em um ambiente compatível.
5. Analisar os resultados e praticar os conceitos apresentados.

## 🛠️ Documentação e Artefatos Técnicos

O repositório contém pastas com exercícios e arquivos relacionados ao desenvolvimento dos algoritmos.

**Tecnologias e ferramentas:**
- GitHub — hospedagem e organização do código.
- Linguagem de programação — utilizada nas atividades desenvolvidas em aula.
- `.classpath` — arquivo de configuração associado a projetos Java, caso seja utilizado nesse ambiente.
